# Project Documentation

Welcome to the documentation for **The Invisible Injury** website.

This folder explains how the project is organized, how the visual design works, how routing works, and how to make changes safely. It is written for someone who is learning to code.

## Start Here

Read the documents in this order:

1. [Beginner Guide](beginner-guide.md) - basic coding and project concepts.
2. [Architecture](architecture.md) - how the React application is put together.
3. [Styling Guide](styling.md) - colors, fonts, spacing, responsive behavior, and visual patterns.
4. [Pages and Content](pages-and-content.md) - every page, route, and piece of content.
5. [Development Workflow](development-workflow.md) - how to edit, test, and review changes.
6. [GitHub Workflow](github-workflow.md) - how to pull, commit, and push work.
7. [Troubleshooting](troubleshooting.md) - common problems and fixes.

The root [README](../README.md) contains the shortest setup guide. These documents provide the deeper explanation.

## Project At A Glance

- Framework: React 19
- Language: TypeScript
- Build tool: Vite
- Routing: React Router
- Styling: plain CSS
- Package manager: npm
- Main source directory: `src/`
- Static files: `public/`
- Production output: `dist/`

## Important Rule

The website is an educational project about concussion awareness. Its content is informational and should not be treated as medical advice. When changing health-related text, check the wording carefully and use trustworthy medical sources.
